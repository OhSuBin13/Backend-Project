# Backend Project

간단한 백엔드 프로젝트들을 구현하고 기록하기 위한 저장소입니다.

작은 단위의 프로젝트를 반복해서 만들면서 API 설계, 데이터 처리, 인증/인가까지 단계적으로 정리하는 것을 목표로 합니다.

## 목표

- 다양한 백엔드 주제를 작은 프로젝트 단위로 실습
- 기능 구현뿐 아니라 구조화, 예외 처리, 테스트 습관 정리

## 진행 방식

이 저장소에는 하나의 큰 서비스보다, 목적이 분명한 여러 개의 작은 백엔드 프로젝트를 추가합니다.

예시:

- CRUD API
- 인증/인가 기반 API
- 파일 업로드 API
- 외부 API 연동 서버
- 배치/스케줄링 예제
- 캐시 적용 예제

## 디렉토리 구조 예시

```text
backend_project/
├─ README.md
├─ projects/
│  └─ ...
```

## 프로젝트 작성 원칙

- 각 프로젝트는 독립적으로 실행 가능하도록 구성
- 프로젝트별로 별도 `README.md`를 두고 실행 방법과 핵심 기능 정리
