# JAX/Flax Addition Transformer

JAX, Flax, Optax로 구현한 문자 단위 causal Transformer 덧셈 실험입니다. 모델은 `0`부터 `999`까지의 두 정수를 입력받아, 고정 길이 시퀀스 안에서 덧셈 결과를 생성하도록 학습됩니다.

예시는 다음과 같은 문자열 형태로 구성됩니다.

```text
123+456= 579
999+999=1998
```

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `addition_transformer_colab.ipynb` | Colab에서 바로 실행할 수 있는 JAX/Flax/Optax 학습 노트북 |

## 실험 설정

| 항목 | 값 |
| --- | --- |
| 실행 장치 | `CudaDevice(id=0)` |
| Vocabulary | `0123456789 +=` |
| Vocabulary 크기 | 13 tokens |
| 입력/출력 시퀀스 길이 | 12 |
| Batch size | 4096 |
| 학습 step | 1500 |
| 파라미터 수 | 10,652,557 (10.65M) |
| 모델 구조 | 6-layer causal Transformer |
| Hidden size | 384 |
| Attention heads | 6 |
| Feed-forward size | 1536 |
| Optimizer | AdamW |
| Learning rate | warmup cosine decay, peak `3e-4` |

학습 데이터는 매 step마다 무작위로 생성됩니다. 각 샘플은 3자리 이하의 두 정수 `a`, `b`와 정답 `a + b`를 고정 길이 문자 토큰으로 표현합니다. 손실과 정확도는 답안 영역에 해당하는 토큰에 대해서만 계산합니다.

## 실행 방법

1. Google Colab에서 `addition_transformer_colab.ipynb`를 엽니다.
2. `Runtime -> Change runtime type`에서 TPU 또는 T4 GPU 런타임을 선택합니다.
3. 노트북의 셀을 위에서 아래로 실행합니다.

필요한 패키지가 없으면 노트북이 `flax`, `optax`를 자동으로 설치합니다.

## 평가 지표

| 지표 | 의미 |
| --- | --- |
| `eval loss` | 답안 토큰에 대한 cross entropy loss |
| `token acc` | 답안 영역의 개별 토큰 정확도 |
| `exact acc` | 정답 문자열 전체가 완전히 일치한 비율 |

## Greedy 샘플 결과

학습 후 greedy decoding으로 확인한 샘플 예측은 모두 올바른 덧셈 결과를 생성했습니다.

| 입력 | 모델 출력 |
| --- | --- |
| `7 + 42` | `  7+ 42=  49` |
| `99 + 1` | ` 99+  1= 100` |
| `123 + 456` | `123+456= 579` |
| `908 + 77` | `908+ 77= 985` |
| `999 + 999` | `999+999=1998` |

## 결과 해석

이 실험에서는 3자리 정수 덧셈이라는 제한된 문제 공간에서 약 10.65M 파라미터의 causal Transformer가 빠르게 수렴했습니다. 초기에는 답안 토큰 정확도가 낮았지만, 100 step에서 `exact acc` 0.1609까지 상승했고 200 step부터는 평가 배치에서 완전 일치 정확도 1.0000을 유지했습니다.

다만 평가는 학습과 동일한 분포인 0부터 999까지의 무작위 덧셈 샘플에서 수행됩니다. 따라서 이 결과는 고정 길이 3자리 덧셈 분포에 대한 수렴을 의미하며, 더 긴 자리수나 다른 형식의 입력으로 일반화된다는 뜻은 아닙니다.
